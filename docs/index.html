The first of its kind

NTFSKit is the world's first pure-FSKit NTFS driver with Kernel-Offloaded I/O: the macOS kernel writes your file data directly to disk while the driver only maps extents — native-class speed from a userspace driver that can never panic your kernel.

⚡ Kernel-fast

Kernel-Offloaded I/O + allocate-without-zeroing writes. Your disk is the bottleneck, not the driver.

🛡 Safe by design

No kernel extension, no Reduced Security, survives macOS updates. Real fsck with NTFS journal replay.

😴 Hibernation-smart

Windows Fast Startup detected → safe read-only mount with a plain-language fix, not a mystery error.

🍎 Mac-native files

Extended attributes stored as NTFS ADS — no ._ litter, round-trips to Windows. Spotlight indexable.

🧰 Disk tools built in

First Aid, format as NTFS from Disk Utility, per-disk read-only, menu bar control. (Pro)

🔓 Open core

The driver is GPL-2.0 open source, free forever. Pro app conveniences fund development.
